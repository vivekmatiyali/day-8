# Day 8 - Resume Webpage Using HTML & CSS

## Project Overview
This project is a personal resume website created using only HTML and CSS.
The objective of this task is to convert a traditional resume into a modern
webpage format while maintaining a clean and professional design. The
webpage contains personal details, technical skills, education, work
experience, languages, awards, and a declaration section.

## Technologies Used
- HTML5
- CSS3

## Features
- Professional two-column resume layout
- Contact information section
- Technical skills categorization
- Profile summary section
- Work experience details
- Education information
- Languages and achievements section
- Responsive and clean user interface
- Custom color theme using CSS variables

## Folder Structure
```
Resume-Project/
│
├── index.html
├── style.css
└── README.md
```

## HTML Concepts Used
- Basic HTML structure
- Headings (h1 to h4)
- Paragraphs (p)
- Lists (ul, li)
- Div containers
- Linking external CSS file

## CSS Concepts Used
- CSS variables (`:root`)
- Flexbox layout
- Width and margin properties
- Typography styling
- Colors and backgrounds
- Borders and padding
- Box sizing
- Custom section styling

## Sections Included in Resume
- **Contact Information** — location, phone number, email address
- **Technical Skills** — programming languages, data science tools, web
  development skills, cybersecurity fundamentals
- **Profile Summary** — a brief introduction describing interests in Data
  Science and Cybersecurity
- **Work Experience** — Data Science internship, Cybersecurity training
  project, academic projects
- **Education** — Bachelor of Computer Applications, Intermediate education
- **Additional Information** — languages known, awards and achievements,
  declaration

## Learning Outcomes
After completing this project, I learned:
- How to structure a complete webpage using HTML.
- How to design professional layouts using CSS Flexbox.
- How to use CSS variables for maintaining consistent colors.
- How to convert a PDF resume into a web-based resume.
- How HTML and CSS work together to create attractive user interfaces.

## Output
The final output is a professional resume webpage that resembles a real
resume and can be viewed directly in any web browser.

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Run the file using Live Server or directly open it in any browser.
